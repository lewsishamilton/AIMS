required); the source id is kept here so each one can be traced or replaced.

**Replace these with real AIMS photographs when they exist.** Stock images on a
hospital's own pages read to visitors as that hospital's facilities, so they are
used here only where the picture is plainly illustrative, never to stand in for
a named AIMS ward, lab or theatre.

haemodialysis image, and those cards render in the no-photo variant instead.
